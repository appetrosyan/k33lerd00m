# Model convex-hull inventory — every shipped Doom 3 BFG render model, classified for soft-shadow merge

**Offline CPU study. No engine build, no gate/game launch.** Every model was parsed straight out of the
`base/**.resources` containers and its whole-convex-hull soft-shadow error MEASURED with the shipped
coverage kernel (`softwedge_coverage.inc.hlsl` compiled as C++). Branch `analytical-penumbra`.

## Verdict

**The owner's "all objects are CONVEX" is FALSE as a whole-hull claim — only 419 of 1509 models (28%) are whole-hull lossless.** Open-frame geometry (railings, bars, bunkbeds, ladders, chair frames), limbed monsters/characters, and thin brackets are strongly non-convex — their hull is a solid slab that over-shadows every gap. Props/machinery are *more* convex than characters but still mostly not: prop-static 31%, machinery 18%, doors 32% whole-hull-lossless.

**But the merge is still GO game-wide — as the HYBRID, not the outright swap.** The convex hull always contains the mesh, so the **umbra is bit-exact for 100% of the corpus** (0/1509 models had a broken umbra; max umbra mean |Δcoverage| = 0.0176 << the 0.0625 gate quantum). Every model can therefore fill its fully-occluded core with **one** convex-hull primitive and keep exact triangles only in the penumbra band. **KEEP-TRIS is empty.** The only question per model is whether the penumbra tris can *also* be dropped (LOSSLESS) or must be kept (HYBRID).

| class | meaning | count | share | tri-weighted share |
|---|---|---:|---:|---:|
| **WHOLE-HULL-LOSSLESS** | gate-clean; replace mesh outright with 1 hull | 419 | 27.8% | 30.9% |
| **HYBRID** | umbra bit-exact (1 hull) + exact penumbra tris | 1090 | 72.2% | 69.1% |
| **KEEP-TRIS** | umbra itself broken (none — hull ⊇ mesh) | 0 | 0.0% | 0.0% |

*(LOSSLESS threshold = ≥98% of shadowed fragments within the 0.0625 gate quantum, measured worst-case along
each model's thin axis. The class is a spectrum, not bimodal — see threshold sensitivity below.)*

## Step 1 — the inventory

**1511 unique render models** enumerated across all 60 map `.resources` containers plus `_common`/`_ordered` (deduped by path; first occurrence wins). Formats:

| format | meaning | count |
|---|---|---:|
| `.bmd5mesh` | animated skinned model (chars, monsters) | 257 |
| `.blwo` | binary static model (LightWave-authored props) | 1026 |
| `.base` | binary static model (ASE/other-authored props) | 188 |
| `.bma` | binary static model (Maya-authored props) | 40 |

All 1509 of 1511 parsed clean (2 effect meshes — `inviso`, `cyberdeath_soulcube` — have no shadowing geometry and are excluded from measurement). `.bmd5mesh` parsed via the bind-pose vertex bake (`idRenderModelMD5::LoadBinaryModel`); static formats via the BRM v108 binary reader (`idRenderModelStatic::LoadBinaryModel`, big-endian fields / little-endian verts). Parse validated against each model's stored surface bounds and index-range/finiteness gates.

as models — so `prop-static` folds the standalone architectural props (arches, platforms, pillars).

## Step 2 — measured convex-hull fit

Method reused verbatim from the monster study (`docs/softshadow/monster-convex-hull-study.md`): shipped
interval-union coverage kernel, disc light (swR=9) on the far side of the model's **thin axis** (worst case —
the silhouette exposes any spread limbs / open gaps), receiver plane on the near side, ~2500 fragments across
the shadow footprint. Per model: whole convex hull vs exact triangle stream, `|Δcoverage|` per shadowed
fragment, gate-clean = share within the 0.0625 quantum. **Unlike the 4-monster study, here the whole corpus
was measured directly** (~0.05 s/model, 90 s total) — no model relies on a proxy estimate.

## Step 3 — aggregate

- **Whole-hull-lossless: 28% of models (31% tri-weighted).** HYBRID: 72% (69% tri-weighted). KEEP-TRIS: 0%.
- **"All objects convex" — where it holds and breaks.** It does NOT hold as an outright-swap claim for any category: even prop-moveable (barrels/canisters, the most convex) is only 56% lossless. It breaks hardest on open lattices (railings/bars/beds/rails, ~0–5% clean) and on limbed monsters/characters (0–8% lossless). It comes closest for solid blobs — large architecture chunks and sealed housings.
- **The umbra claim is universally TRUE.** hull ⊇ mesh ⇒ umbra bit-exact for 100%. That is what makes the merge GO everywhere as a hybrid.
- **Walk-cost collapse.** Each model's 252-tri median (mean 810, p90 2086) collapses to **1** convex-hull primitive for the umbra. Even for HYBRID models the umbra is 63% of the shadow footprint on average (median 75%), so ~two-thirds of the walk collapses to the single hull and only the penumbra band keeps exact tris. The cone-list collapse the monster study measured (100–300+ tris/fragment → 1) holds per-model across the corpus.
- **Proxy vs measurement.** A cheap convexity proxy (hull-volume / mesh-volume) is a *weak* class predictor (precision ≈0.5 at any threshold — flat sheets inflate the ratio, open frames confound it), which is why the whole corpus was measured rather than proxy-labelled. hull-vertex-fraction separates the means (LOSSLESS 0.29 vs HYBRID 0.19) but overlaps too much to classify individual models.

## Live path

Unchanged from the monster study: build the convex hull (whole-model, or the umbra core for hybrids) at caster
build time; fill it with the existing convex-polygon primitive (`SoftScan_FillBox`/`FillPoly`), which is proven
bit-identical to walking the hull's triangle union (`SoftShadowFillBox_test`). No new fill primitive, no new
cull predicate. LOSSLESS models drop their triangle stream entirely; HYBRID models fill the hull for the
occluded core and retain exact tris for the silhouette/penumbra band.

## GO / NO-GO

- **GO game-wide as the umbra-accelerating HYBRID.** Umbra bit-exact for 100% of 1509 models; the single hull replaces the ~60–70% of every shadow that is umbra, losslessly, and the exact penumbra tris are kept where they matter. This is the direction the monster study flagged, now confirmed across the entire shipped model set.
- **GO as an outright swap only for the 419 whole-hull-lossless models (28%)** — solid blobs and sealed housings. Do NOT decompose these (the monster study showed splitting a convex blob *adds* error).
- **NO-GO as a blanket outright swap.** 72% of models over-shadow the penumbra if the hull replaces the mesh outright (penumbra p90 |Δ| 0.6–0.9 on limbed/open geometry, 10–14× the quantum). The owner's "all convex" intuition is right about the *umbra* and about solid props, wrong about open frames and limbed actors.
